API

Una API clara para cada acción

Envía tu API key en el encabezado X-Api-Key. Cada recurso tiene sus propios endpoints y todas las respuestas usan el mismo formato: validation, status, data y mensage.

  • GET /api/fileRed/cuenta/getByIdPlan, consumo y permisos
  • GET /api/fileRed/almacenes/getAllListar almacenes
  • POST /api/fileRed/almacenes/addCrear almacén
  • PUT /api/fileRed/almacenes/updateRenombrar almacén
  • DELETE /api/fileRed/almacenes/deleteEliminar almacén
  • POST /api/fileRed/carpetas/getAllListar carpetas
  • POST /api/fileRed/carpetas/addCrear carpeta
  • PUT /api/fileRed/carpetas/updateRenombrar carpeta
  • DELETE /api/fileRed/carpetas/deleteEliminar carpeta
  • POST /api/fileRed/archivos/getAllPagesListar archivos paginados
  • POST /api/fileRed/archivos/getByIdConsultar archivo
  • POST /api/fileRed/archivos/addSubir archivo
  • PUT /api/fileRed/archivos/updateReemplazar archivo
  • PUT /api/fileRed/archivos/updateNombreRenombrar archivo

PREGUNTAS FRECUENTES

Lo que más nos preguntan

¿Qué tipos de archivo puedo subir?

Imágenes, video, audio, documentos de oficina, PDF, archivos comprimidos y formatos de datos como JSON, XML y CSV.

¿Qué pasa si me quedo sin espacio?

En prepago verás el aviso de espacio insuficiente y podrás solicitar un plan mayor. En pospago con adicionales activos, los GB extra se suman a tu próximo cargo.

¿Puedo tener varias API keys?

Sí. Crea una llave por aplicación o entorno, con permisos distintos, y revócala cuando quieras sin afectar a las demás.

¿Puedo trabajar con mi equipo?

Sí. Agrega usuarios a tu cuenta y asígnales roles con las acciones exactas que pueden realizar.

¿Cómo pago mi plan?

Nuestro equipo registra tus pagos y abonos. Puedes consultar en todo momento tus cargos pendientes y tu historial.
